# 📁 Documentation AP4

Bienvenue sur le dépôt GitHub du projet **AP4** – BTS SIO SISR.

Ce dépôt centralise l'ensemble de la documentation, des livrables et des ressources techniques liées au projet.

---

## 🗂️ Structure du dépôt

| Dossier/Fichier                  | Description                                                                 |
|----------------------------------|-----------------------------------------------------------------------------|
| 📂 `Assets`                      | Ressources graphiques : logos, images, diagrammes, etc.                    |
| 📂 `Gantt`                       | Fichiers de planification : diagrammes de Gantt, fichiers CSV.             |
| 📂 `Livrable`                    | Documents finaux à remettre dans le cadre du projet.                       |
| 📂 `Sujet AP4`                   | Sujet officiel fourni pour le projet.                                      |
| 📂 `Documentations Techniques`  | Docs techniques (réseau, infra, architecture, etc.).                       |
| 📂 `NET Diagramme`              | Diagrammes réseau (infrastructure, topologie, etc.).                       |
| 📄 `Architecture_Infra_AP4.md`  | Description de l'architecture du projet.                                   |
| 📄 `README.md`                  | Ce fichier de présentation du dépôt.                                       |

---

## 🛠️ Technologies utilisées

- 📦 **Proxmox VE** : Plateforme de virtualisation open source pour machines virtuelles et conteneurs.
- 🔐 **OpenVPN Road Warrior** : Solution VPN sécurisée pour connexions distantes.
- 🌐 **DynFi** : Interface centralisée de gestion de pare-feux compatibles OPNsense.
- 📡 **Stalwart Mail Server** : Serveur de messagerie moderne, sécurisé et modulaire.
- 📊 **Grafana** : Outil de visualisation de données, connecté à Elastic.
- 📺 **Tvheadend** : Serveur de diffusion vidéo.
- 📅 **eBrigade** : Outil de gestion des plannings, événements et utilisateurs pour les structures de sécurité civile.
- 🪟 **Windows Server Core** :
  - 🧠 **Active Directory (AD)** : Gestion centralisée des utilisateurs et des ressources.
  - 🌐 **DNS Server** : Résolution de noms internes.
  - 📡 **DHCP Server** : Attribution automatique des adresses IP sur le réseau.
- 🗃️ Documentation : Rédigée en **Markdown** (`.md`) et disponible en **PDF** si nécessaire.
